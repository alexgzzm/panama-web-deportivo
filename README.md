# Club Deportivo Panamá — Demo frontend

Demo funcional en React (Vite) para presentación a inversionistas. No tiene backend: los datos se guardan en `sessionStorage` y se mantienen mientras la pestaña esté abierta.

## Ejecutar

```bash
npm install
npm run dev
```

## Acceso demo

- Correo: `demo@deportivo.com`
- Contraseña: `demo1234`

También se puede crear una cuenta nueva desde la pantalla de login (vive solo durante la sesión).

Nombre del club y credenciales demo se configuran en `src/config.js`.
